# Scene wishes for V199: The road to Git 3.0, the planned defaults and removals, opting in today, and SHA-256 and reftable repositories locally

Spots are given as section heading plus the first six words of the paragraph in `video/scripts/V199-*.md`. Every label is copied from the script. Git 3.0 is not released: every picture of it carries the word "planned", "announced" or "reported" exactly as the script does, and no picture may draw a planned default as today's behavior or put a date under 3.0 other than the script's "no official date". The lab runs Git 2.55.0; the newest release named is 2.56.0. GitHub-side statements are from documentation and reports, and their caveats stay on the picture.

Placed in this pass with today's library: nothing. The `hash` scene was considered for the format conversion and rejected: it shows one function giving two IDs for two contents, and here two functions give two IDs for one history. The `sandbox` scene was considered for the opt-in and rejected: the script does not describe the lab's isolated configuration in this video, so its box labels would have to be invented.

## 7. History crosses the format boundary only as a stream

- **Spot.** CONCEPT, "History can cross the format boundary", and LIVE TERMINAL DEMO, ""Mismatched algorithms": the two formats cannot".
- **Picture.** Two repositories with a wall between them, `inference` (sha1) and `inference-sha256` (sha256).
- **Steps.**
  1. `refused`: a fetch arrow hits the wall: "fatal: mismatched algorithms: client sha256; server sha1".
  2. `stream`: under the wall a pipe: `git fast-export --all` on the left, `git fast-import` on the right; three commits travel through as text.
  3. `new-ids`: the three commits arrive with the same subjects and new IDs: "Add inference service" `3e283dd` becomes `6daacca`; "Raise batch size to 16" `53a79b6` becomes `587a0ea`; "Pad batches to a fixed length" `c284765` becomes `4fea7f1`.
  4. `lost`: three things stay on the left side, greyed: "Signatures", "commit IDs quoted in messages, issue trackers and CI configuration"; caption "a migration project with a cut-over date, not a setting".
