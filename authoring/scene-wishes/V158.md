# Scene wishes for V158: Script injection through untrusted event fields

No scene of today's library was placed: the `ci` scene shows a run from event to result, not what happens to the text of one `run` step, and nothing in the library shows a value being pasted into a script. Every label below is copied from the script. No picture may show a crafted input: where a value is drawn, draw it as a plain grey block labelled "the VALUE of X" or "the title", never as text. Six pictures.

- **Steps, in order.**
