## 5. A merge commit is a door

- **When.** After the reveal.
- **Spot.** MENTAL MODEL, "Picture the pull request as the", "Ravi opened a door to `develop`", "Where the picture breaks: you can".
- **Picture.** The head branch as a corridor; the merge commit as a door in its wall; behind the door, the room `develop`.
- **Steps.**
  1. `question`: the caption "what would arrive in the base if this were merged now?".
  2. `door`: the door opens: "whatever is behind its second parent walks in with it".
  3. `one-thing`: one item is carried out, "one thing he wanted"; everything else follows through the same door.
  4. `revert`: a second commit closes the door's content but the doorway stays in the wall: "A revert changes the content back and leaves the ancestry in place."
  5. `rebuild`: a new corridor without any door: "Only a branch that never contained the merge is a branch without the door".
