## 2. The pointer and the file can disagree, silently

- **Spot.** LIVE TERMINAL DEMO, "Read the first two commands together." (after snippet `02-new-version`).
- **Picture.** The data file, the pointer, and two observers: Git and the tool.
- **Steps.**
  1. Four rows are appended to `data/raw/tickets.csv`. The pointer still says `2226b23c455b`.
  2. Git looks: `git status --short` prints nothing (the file is ignored).
  3. The tool looks: `python3 tools/dataref.py verify` prints `differs  data/raw/tickets.csv  (pointer sha256:2226b23c455b)`, a cross.
  4. `add`: the pointer becomes `4efbc43184d3`, `"size": 606`. The Git diff is two lines: hash and size.

## 3. Going back is two steps

- **Spot.** LIVE TERMINAL DEMO, "Git moved the pointer. The working" (after snippet `04-time-travel`).
- **Picture.** Two lanes over time: "Git moves the pointer" and "the tool moves the bytes".
- **Steps.**
  1. `git switch -q --detach HEAD~1`: in the Git lane the pointer drops back to `2226b23c455b`. In the bytes lane the file still holds the newer data: a gap opens between the lanes, `differs`.
  2. `python3 tools/dataref.py checkout`: `restored data/raw/tickets.csv from sha256:2226b23c455b`. The lanes agree again.
  3. A small note for Git LFS: the second step is hidden "inside a smudge filter".
