# Scene wishes for V155: Gate briefing: Actions

Spots are given as section heading plus the first six words of the paragraph in `video/scripts/V155-*.md`. Every label is copied from the script. The gate runs nothing on GitHub and no GitHub output appears in it: no picture may look like a captured run. No library scene was placed in this pass: the briefing's own pictures are an answer frame and two lists, and the three commits of the warm-up cannot be drawn exactly with `graph` (the runner holds one commit only, the parent of `80c9cfa` and `29b222b` is not named in this script, and a commit cannot carry a pass or fail mark).

## 1. The answer frame, filled in line by line

- **Spot.** CONCEPT, "**What a strong answer contains.** A"; DIAGRAM (it replaces the ASCII frame); LIVE TERMINAL DEMO, "Try it now, on paper. Thirty" and "One ref, `refs/pull/7/merge`, one commit,"; PRODUCTION EXAMPLE, "The engineer who answers uses the".
- **Picture.** A form with four labelled lines, then three more below a rule.
- **Steps.**
  1. `empty`: the labels only: "event", "ref, commit", "permissions", "runner", then "finding", "next action", "not proven".
  2. `event`: "pull_request (synchronize), pull request 7".
  3. `ref-commit`: "refs/pull/7/merge -> the test merge d04ef31, detached HEAD, one commit, no tags", and under it "(the author's commit is 80c9cfa; main is at 29b222b)". For the try-it-now pause this line stays empty and pulses, then fills with the answer.
  4. `permissions`: "contents: read; every other permission none".
  5. `runner`: "ubuntu-24.04, GitHub-hosted, fresh machine".
  6. `finding`: "the run tested the merge of the head into the current base, not the head."
  7. `next-action`: "merge the base into a detached copy of the branch to reproduce; fix; push."
  8. `not-proven`: "anything about a base that has moved since this test merge was made."; this line gets the highlight: "The last line is not decoration."
- **Why not today.** A `text` fence is drawn line by line in file order; it cannot hold a line empty for a pause or return with the lines of another case.
