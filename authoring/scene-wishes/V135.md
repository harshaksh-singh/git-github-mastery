## 7. MENTAL MODEL, "**How it differs from gitignore.** The", and LIVE TERMINAL DEMO steps 3 to 6

**Picture.** Two matchers side by side fed the same pattern file and the same path: left "Git's matcher (gitignore)", right "CODEOWNERS (documented)". The left one walks directories and stops at a matched directory; the right one labels files one path at a time.

Cases, one per demo step, each showing the two verdicts:

| Pattern lines | Path | Git (from the transcript) | CODEOWNERS (documented) |
|---|---|---|---|
| `*` then `*.py` | `tests/test_classify.py` | line 1, "Git stops at the directory tests/" | a later line owns the file (documented example: `*` then `*.js`) |
| `docs/*` | `docs/build-app/troubleshooting.md` | matched | "but not further nested files" |
| `*.yaml` then `!config/routing.yaml` | `config/routing.yaml` | line 2 decides | negation documented not to work |
| `shard-[0-3].yaml` | `shard-2.yaml`, `shard-7.yaml` | `shard-2.yaml` matched | ranges documented not to work |
| `\#generated.md` | `#generated.md` | matched | escaped hash sign unsupported |
| `/docs/` | `Docs/a.md` | depends on `core.ignoreCase` (false: exit status 1; true: exit status 0) | always case sensitive |

Where the two disagree the right-hand verdict carries a small "documented" tag, never a tick that suggests it was run.
