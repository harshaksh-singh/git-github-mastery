# Git and GitHub video courses from Indian educators (Hindi and English): evaluated catalogue as of 1 October 2026

**How to read these notes (evidence basis).** Every video given its own link below was opened on YouTube on 1 Oct 2026; title, channel, duration, publish date, description and chapter list were read from the watch page itself. A few episode titles cited only as members of a series (e.g. some ProCodrr and Rahul Wagh episodes) were verified from the playlist or channel listing instead. Nothing is listed that could not be verified to exist. Evidence labels used throughout:
- **[T]** = technical content checked against the video's auto-generated captions (YouTube ASR) with keyword-in-context searches for ~40 Git terms. This is a targeted audit, not a full viewing. For Hindi videos the Hindi ASR text (or YouTube's machine translation of it) was searched, so wording is paraphrased, never verbatim, and "term not found" means "not found in auto-captions".
- **[C]** = judged from the creator's chapter list and description only (no usable captions).
- **[M]** = title/metadata only.
- View counts were deliberately not used to rank anything.
- Dates are the YouTube publish date (YYYY-MM-DD, as reported in YouTube's page metadata).
- Reference facts used to judge "outdated": GitHub stopped accepting account passwords for Git operations on 13 Aug 2021 — [GitHub changelog](https://github.blog/changelog/2021-08-12-git-password-authentication-is-shutting-down/); `git init` still defaults to `master` (docs for Git 2.54 say this changes to `main` in Git 3.0) — [git-init docs](https://git-scm.com/docs/git-init); current `git pull` docs list four integration modes and say `--ff-only` is the default, failing on divergence — [git-pull docs](https://git-scm.com/docs/git-pull); GitHub recommends fine-grained personal access tokens over classic and says to treat tokens like passwords — [GitHub docs](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens); on 1 Oct 2026 the newest `actions/checkout` release was v7.0.1 (20 Jul 2026), with v4.4.0/v5.1.0/v6.1.0 still receiving releases — [actions/checkout releases](https://github.com/actions/checkout/releases); newest Git tag was v2.56.0 — [git/git tags](https://github.com/git/git/tags).

## CampusX (Nitish Singh): What Git/GitHub videos or playlists exist, including Git content embedded in MLOps / data science / DSMP courses?

### Takeaway
CampusX has no current, free, full Git course: its public Git videos are four short items from Oct 2019 to Jun 2020 (no captions, pre-`main`, pre-token era), while its two substantial Git sessions (2h11m and 2h09m, Dec 2022, inside the DSMP 2022-23 playlist) are members-only. Its free "100 Days of MLOps" playlist stopped at 4 videos; only one (Nov 2024) touches DVC pipelines and GitHub Actions, and only as a narrated walkthrough, so CampusX is useful for MLOps framing in Hindi but not for learning Git itself.

### Inferences
- The DVC/S3/CI demo repositories dated June–July 2024 have no matching public YouTube videos, so those sessions (DVC data versioning, DVC+S3 remotes, CI) are most likely taught only inside the paid DSMP 2.0 / MLOps course.
- The Dec 2022 two-part DSMP Git sessions (4h20m total) are probably CampusX's most complete Git teaching, but they cannot be recommended in a free curriculum and their correctness cannot be checked from outside.
- For a curriculum, CampusX fits only at the MLOps stage, as a Hindi conceptual overview of where Git, DVC pipelines, a model registry and CI/CD sit in an ML project; it does not teach Git mechanics.
- The 2019–20 public videos pre-date GitHub's token-only authentication and the `main` default, so their push/authentication steps are very likely outdated even though this could not be confirmed without captions.

### Gaps
- The four 2019–20 videos have no caption track (only one has a Hindi ASR track, and it is a 7-minute Q&A), so their technical statements could not be audited; assessment is from chapters/descriptions only.
- Members-only sessions (Dec 2022, Feb 2023) could not be opened; topics, correctness and currency are unknown.
- The detailed syllabus of the paid "Git & GitHub" and "MLOps" courses could not be retrieved (the site lists course names only; a Scribd copy of the DSMP 2.0 syllabus was not readable). A third-party GitHub README attributes a free four-session "End-to-End ML Project using MLOps" course (sessions on version control and DVC) to CampusX with a different instructor name; I could not verify this on CampusX's own site, so it is not catalogued.

## CodeWithHarry: What Git and GitHub tutorials exist (Hindi), including older tutorials, newer one-shots and Git sections of longer courses?

### Takeaway
CodeWithHarry has two generations of Git content: dated 2018–2020 videos, and a new 2h31m one-shot published 12 July 2026 that is the most current Hindi beginner Git video found (uses `git switch`/`git restore`, SSH keys, fetch-vs-pull, rebase, stash, tags, fork/PR, GitHub Desktop, VS Code). The new video still omits every "undo history" tool (no reset, revert, reflog, cherry-pick or amend in the captions) and has no GitHub Actions, and the old dedicated Git playlist linked from his descriptions no longer exists.

### Inferences
- For a 2026 learner the 2019 video should be replaced by the July 2026 one-shot: the 2019 chapter list is built around `git checkout`, has no merge-conflict, stash, rebase, fork or pull-request chapter, and was recorded when GitHub still accepted passwords and defaulted to `master`.
- The 2026 one-shot is a good first Hindi pass (stage 1–2 of a curriculum) but must be followed by another resource for reset/revert/restore-of-history, reflog and cherry-pick, which it does not contain.
- The "branch = copy of main" sentence at ~57 min is the kind of statement a rigorous curriculum should explicitly correct; the video itself corrects it 15 minutes later, so pointing learners to the later statement is enough.
- The roughly 5-hour "Complete Git Tutorials" collection listed by Class Central probably corresponds to the now-deleted playlist; it is no longer usable as a playlist.

### Gaps
- The 2019 video has no captions, so statements such as how push authentication is shown could not be checked; it is assessed from its chapter list only.
- The contents of the deleted Git playlist could not be recovered (the Class Central page returned HTTP 403 to my fetch).
- The accompanying handbook/cheat sheet on codewithharry.com was not reviewed.
- Whether the 2026 video demonstrates anything visually that is not spoken (e.g. a reset shown on screen without being named) cannot be ruled out from captions alone.

## Which other Indian educators have technically strong Git/GitHub content (Kunal Kushwaha, Apna College, Chai aur Code / Hitesh Choudhary, Piyush Garg, Love Babbar, TrainWithShubham, Abhishek Veeramalla, Krish Naik, Telusko, Anuj Bhaiya, Sheryians, Thapa Technical, Gaurav Sen, Arpit Bhayani, freeCodeCamp Hindi, and others discovered)?

### Takeaway
The technically strongest items are not the most famous ones: Chai aur Code's Hindi course (objects, HEAD, rebase, reflog, SSH), Rahul Wagh's and Ansh Lamba's long English courses (interactive rebase, bisect, cherry-pick, reflog, stash), ProCodrr's Hindi reset/revert/reflog episode, and four internals videos (Gaurav Sen, Sanket Singh, Harsh Kapadia, Piyush Garg's "Build Your Own Git"). The very popular short one-shots (Apna College, Anuj Bhaiya, Love Babbar, Krish Naik Hindi, Sheryians) are shallow and several carry dated or imprecise statements; no audited Indian video covers bisect in Hindi from a major channel, GitHub Actions security, or packfile/index internals in depth.

### Inferences
- Depth and popularity diverge sharply: the short one-shots (Apna College, Anuj Bhaiya, Love Babbar, Krish Naik Hindi, Sheryians) cover roughly the same add/commit/push/branch/merge loop, while the less-watched long courses (Chai aur Code, Rahul Wagh, Ansh Lamba, ProCodrr, Tech with Jatin) are where reset/revert, reflog, cherry-pick, interactive rebase and bisect actually appear.
- Chai aur Code's Hindi course is the best single Hindi bridge from beginner to intermediate because it is the only audited Hindi one-shot that names Git's object types, defines HEAD correctly, uses reflog, and states the password-authentication change; it should still be supplemented for revert/restore, cherry-pick and fetch-vs-pull.
- Hitesh Choudhary's Hindi and English versions are not equivalent: the Hindi captions contain blob/tree vocabulary and a reflog-plus-reset recovery, the English captions do not; a curriculum should say which version it means.
- The four internals videos (Gaurav Sen, Sanket Singh Part 2, Harsh Kapadia, Piyush Garg's build-your-own series) complement each other: Gaurav Sen is strongest on compression/packfiles, Harsh Kapadia on refs and the index file, Sanket Singh on trees and the key-value model, Piyush Garg on re-implementing plumbing commands in Hindi.
- For DevOps-flavoured learners, Abhishek Veeramalla's 2023 Git days are conceptually useful (merge vs rebase vs cherry-pick, clone vs fork, branching strategy) but his 2026 DevSecOps Day-2 video is the more valuable and current item because it is the only audited video that shows rulesets, CODEOWNERS, gitleaks and Dependabot together.
- Institute compilations (Edureka, Simplilearn) are stitched from older segments and carry title years later than their publish dates, so their "2024"/"2026" labels should not be read as evidence of currency.

### Gaps
- Kunal Kushwaha's tutorial could not be transcript-audited (the caption track is a mis-detected Hindi ASR of English speech); the command list comes from a learner's notes, so precise wording of his explanations (e.g. how he defines a branch) is unverified.

### Inferences
- A rigorous curriculum cannot be assembled from one creator: a workable Hindi sequence needs at least three sources (a current beginner one-shot, Chai aur Code for objects/rebase/reflog, and ProCodrr or Not Your College for reset/revert), plus English material for interactive rebase and bisect.
- Videos that never show SSH or tokens (Apna College, College Wallah, Sheryians, M Prashant) probably rely on a credential helper or VS Code/browser sign-in that happens off-narration; learners following along on a fresh machine may hit an authentication step the video does not explain.
- "○" in the matrix means the term was not found in auto-captions; a command shown on screen but never spoken would be missed, so the matrix slightly under-reports rather than over-reports coverage.

### Gaps
- Kunal Kushwaha's and CodeWithHarry's 2019 rows rest on chapter lists (and, for Kunal, a learner's notes), not transcripts.
- The matrix does not grade quality of explanation for each cell; only the statements quoted elsewhere in these notes were checked in context.
- Tags, hooks, worktrees, submodules and LFS were not systematically audited across the videos.

## Which statements or practices in each video are outdated or technically imprecise as of October 2026?

### Takeaway
The most consequential problems are (1) authentication: three audited videos still tell learners to push over HTTPS with a GitHub password, and the two that teach tokens use classic PATs, one of them pasted into the remote URL; (2) conceptual shortcuts: "a branch is a copy" (Apna College, Sheryians, Krish Naik Hindi, Rahul Wagh, early in CodeWithHarry 2026) and "HEAD is the latest commit" (Apna College, TrainWithShubham, Piyush Garg); (3) unguarded `git push -f` after reset (Piyush Garg, Rahul Wagh); and (4) stale GitHub Actions versions (checkout@v2/v3) in Krish Naik, Abhishek Veeramalla and Kunal Kushwaha videos, against a current v7.

### Inferences
- Every video published before 13 Aug 2021 that pushes over HTTPS (CampusX 2019–20, CodeWithHarry 2019–20, Love Babbar 2020, Technical Guftgu 2020, Anuj Bhaiya May 2021, Telusko's 2019 compilation, codebasics' series, and Kunal Kushwaha's 1 Aug 2021 tutorial if it shows a credential prompt) necessarily shows a flow that no longer works as recorded, and all pre-2023 videos show an older GitHub web UI; this is inferred from dates, not individually verified on screen.
- Using `master` locally is not an error in 2026 (Git 2.56 still defaults to it), but a curriculum should tell learners why `git push origin master` in CampusX/TrainWithShubham demos fails against a GitHub repository created with `main`.
- The combination "reset --hard then push -f" taught as a routine undo (Piyush Garg, Rahul Wagh) is the single most dangerous habit in this catalogue for team settings and should be paired with `--force-with-lease`, protected branches and `git revert` in any curriculum that links to those videos.
- Actions videos from Indian DevOps channels are project walkthroughs optimised for "pipeline goes green"; none can be used as a security reference.

### Gaps
- I did not check any video frame-by-frame for on-screen UI, so "old GitHub UI" is inferred from publish dates.
- Whether Kunal Kushwaha's tutorial shows a password or token prompt is unknown (no usable captions; the learner notes mention no authentication).
- I did not search captions for `--force-with-lease`, `pull.rebase`, `init.defaultBranch` or "fine-grained" in every video; those absences are established only for the passages read (and, for classic vs fine-grained, for the TrainWithShubham workshop and Ansh Lamba).
- Machine-translated and ASR captions can misrender a speaker's qualification, so each "imprecise statement" should be re-checked by a human viewer at the linked timestamp before being quoted in a published report.

## Honest gaps: at which curriculum stages is there no strong Indian-educator video, so that international sources or official docs must be used?

### Takeaway
Indian-educator YouTube content is adequate through "intermediate commands" and thin beyond it. There is no strong Indian video on packfile/index/ref internals beyond introductory demos, on systematic disaster recovery (reflog/fsck, undoing force-pushes, removing secrets from history), on advanced rebase (`--onto`, autosquash, rerere), on bisect in Hindi, on GitHub platform governance (rulesets beyond one demo, fine-grained PATs, signed commits, merge queue), on GitHub Actions security (OIDC, least-privilege permissions, SHA pinning, `pull_request_target`) or on Git-centred MLOps beyond basic DVC; those stages need international sources and official documentation.

### Inferences
- For the curriculum's later stages (internals beyond objects, incident recovery, advanced rebase, Actions security, platform governance), the practical choice is official docs (git-scm.com reference and Pro Git, GitHub Docs) plus international talks; Indian-educator videos can serve as motivation or first exposure only.
- The gap is structural: Indian channels optimise for placement/interview and "deploy a project" outcomes, so content clusters around the first push, the first PR and a green pipeline. That explains why reflog, bisect, rulesets and OIDC are rare even in 2025–26 uploads.
- Hindi-medium learners are well served up to reset/revert/reflog basics and DVC basics, but will need English for interactive rebase, bisect, internals depth and anything about Actions security; a curriculum for Hindi-first learners should budget for that language switch explicitly.
- Because several strong items are from small or single-video sources (Harsh Kapadia, CODERS NEVER QUIT, Vikash Das, ProCodrr), link rot is a real risk; the curriculum should name the official-doc fallback for each stage.

### Gaps
- "Not found" reflects YouTube search and channel-search results on 1 Oct 2026 using the queries linked above; unlisted, paid, cohort-only or newly uploaded videos, and content in other Indian languages, may exist.
- I did not survey Udemy, Coursera, NPTEL/SWAYAM or creators' own course sites for advanced Git modules.
- I did not verify the international alternatives themselves; that is covered by other researchers' notes.
