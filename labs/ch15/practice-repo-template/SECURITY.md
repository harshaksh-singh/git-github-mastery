# Security policy

## Supported versions

Only the latest commit on `main` is supported. This is a practice repository.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Report it privately to the maintainers. If private vulnerability reporting is enabled for
this repository, use it; otherwise contact a maintainer directly. Include the affected
file, the steps to reproduce, and the impact you expect.

You can expect an acknowledgement within five working days.
